# ATELIER - Design Studio Portfolio

A luxurious, minimalist designer portfolio website featuring elegant black and white aesthetics.

## Features

- 🎨 Minimalist design with luxury brand aesthetics
- ⚫⚪ Pure black and white color scheme
- ✨ Smooth animations and transitions
- 🖱️ Custom cursor effects
- 📱 Fully responsive design
- 🎭 Parallax scrolling experience

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Cormorant Garamond & Montserrat)
